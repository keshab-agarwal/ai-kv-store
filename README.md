# Distributed In-Memory KV Store Project

Project tasks are split into dedicated folders:
- `task1_kv`: distributed linearizable KV store
- `task2_ycsb`: YCSB Zipfian benchmark harness and binding
- `task3_harness`: correctness harness with fault injection + Porcupine checker
- `task4_tla`: TLA+ specification + TLC configs (including bug mode)
